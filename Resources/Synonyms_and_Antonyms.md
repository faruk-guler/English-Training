# Synonyms and Antonyms - Zıt ve Eş Anlamlı Kelimeler Sözlüğü

Bu kılavuz, özellikle **IELTS, TOEFL, YDS ve genel konuşma/yazma (Writing & Speaking)** becerilerinde sürekli "very (çok)", "good (iyi)", "bad (kötü)" gibi basit kelimeleri tekrar etmek yerine, anlatımı zenginleştirecek üst düzey eş anlamlıları (Synonyms) ve zıt anlamlıları (Antonyms) sunar.

## 1. Zengin Sıfatlar (Advanced Adjectives)

| Temel Kelime | Türkçe Anlamı | Daha Güçlü Eş Anlamlıları (Synonyms) | Zıt Anlamlıları (Antonyms) |
| :--- | :--- | :--- | :--- |
| **Good** | İyi, kaliteli | Excellent, Superb, Outstanding, Marvelous, Exceptional | Bad, Awful, Terrible, Poor, Inferior |
| **Bad** | Kötü, berbat | Dreadful, Terrible, Horrible, Atrocious, Deficient | Good, Splendid, Wonderful, Superior |
| **Big** | Büyük, devasa | Huge, Massive, Enormous, Gigantic, Immense, Colossal | Tiny, Miniature, Microscopic, Petite, Small |
| **Small** | Küçük, ufak | Tiny, Minuscule, Compact, Petite, Minute | Enormous, Gigantic, Immense, Massive |
| **Happy** | Mutlu, neşeli | Delighted, Joyful, Thrilled, Ecstatic, Elated, Cheerful | Depressed, Miserable, Sorrowful, Gloomy, Dejected |
| **Sad** | Üzgün, kederli | Miserable, Melancholy, Heartbroken, Despondent, Woeful | Joyful, Cheerful, Delighted, Jubilant |
| **Important** | Önemli, hayati | Crucial, Vital, Essential, Significant, Paramount, Pivotal | Trivial, Insignificant, Negligible, Minor |
| **Interesting**| İlginç, çekici | Fascinating, Captivating, Intriguing, Compelling, Absorbing | Boring, Dull, Tedious, Monotonous |
| **Boring** | Sıkıcı, tekdüze | Tedious, Monotonous, Dull, Uninspiring, Mind-numbing | Engaging, Thrilling, Fascinating, Stimulating |
| **Beautiful** | Güzel, çekici | Gorgeous, Stunning, Breathtaking, Attractive, Exquisite | Ugly, Hideous, Unattractive, Grotesque |
| **Ugly** | Çirkin, nahoş | Hideous, Reppulsive, Grotesque, Unsightly | Gorgeous, Beautiful, Stunning, Attractive |
| **Smart / Clever**| Zeki, akıllı | Brilliant, Intelligent, Astute, Sharp, Intellectual, Wise | Foolish, Stupid, Ignorant, Naive, Dull |
| **Tired** | Yorgun, bitkin | Exhausted, Drained, Fatigued, Weary, Spent | Energetic, Invigorated, Lively, Refreshed |
| **Angry** | Kızgın, öfkeli | Furious, Enraged, Incensed, Indignant, Irate | Calm, Serene, Composed, Placated, Peaceful |
| **Fast** | Hızlı, süratli | Rapid, Swift, Speedy, Prompt, Brisk | Sluggish, Slow, Leisurely, Dilatory |
| **Slow** | Yavaş, ağırkanlı | Sluggish, Lethargic, Gradual, Dilatory | Rapid, Swift, Fast, Quick |
| **Difficult / Hard**| Zor, çetin | Challenging, Arduous, Demanding, Tough, Formidable | Easy, Effortless, Simple, Straightforward |
| **Easy** | Kolay, zahmetsiz | Effortless, Simple, Straightforward, Painless | Arduous, Challenging, Demanding, Complex |
| **Rich / Wealthy**| Zengin, varlıklı | Affluent, Prosperous, Opulent, Well-off | Impoverished, Poor, Destitute, Penniless |
| **Poor** | Yoksul, fakir | Impoverished, Destitute, Indigent, Needy | Wealthy, Affluent, Prosperous, Opulent |
| **Dangerous** | Tehlikeli, riskli | Perilous, Hazardous, Risky, Treacherous | Safe, Secure, Harmless, Protected |
| **Safe** | Güvenli, emin | Secure, Harmless, Shielded, Immune | Perilous, Hazardous, Dangerous, Vulnerable |
| **Famous** | Ünlü, tanınmış | Renowned, Noted, Celebrated, Eminent, Distinguished | Obscure, Unknown, Anonymous, Forgotten |
| **Bright** | Aydınlık, parlak | Luminous, Radiant, Brilliant, Dazzling | Dim, Dark, Somber, Gloomy, Obscure |
| **Dark** | Karanlık, loş | Gloomy, Dim, Somber, Pitch-black, Murky | Bright, Luminous, Radiant, Well-lit |

## 2. Zengin Eylem Fiilleri (Action Verbs)

| Temel Fiil | Türkçe Anlamı | Daha Güçlü Eş Anlamlıları (Synonyms) | Zıt Anlamlıları (Antonyms) |
| :--- | :--- | :--- | :--- |
| **Like / Love** | Sevmek, beğenmek | Admire, Appreciate, Adore, Cherish, Relish | Loathe, Detest, Despise, Abhor, Dislike |
| **Hate** | Nefret etmek | Detest, Loathe, Despise, Abhor, Scorn | Adore, Love, Admire, Cherish |
| **Start / Begin** | Başlamak, başlatmak | Initiate, Commence, Launch, Embark on, Inaugurate | Conclude, Terminate, Cease, Finish, Halt |
| **Stop / Finish** | Durdurmak, bitirmek | Terminate, Cease, Halt, Conclude, Finalize | Initiate, Commence, Resume, Continue, Launch |
| **Help** | Yardım etmek | Assist, Support, Aid, Facilitate, Foster | Hinder, Obstruct, Impede, Inhibit |
| **Show** | Göstermek, sergilemek | Demonstrate, Display, Exhibit, Reveal, Manifest | Conceal, Hide, Mask, Obscure |
| **Hide** | Saklamak, gizlemek | Conceal, Camouflage, Mask, Cloak, Shroud | Reveal, Expose, Disclose, Manifest |
| **Change** | Değiştirmek | Alter, Modify, Transform, Adapt, Convert | Preserve, Maintain, Retain, Stabilize |
| **Increase** | Artırmak, yükselmek | Boost, Elevate, Escalate, Augment, Enhance | Decrease, Diminish, Reduce, Plummet |
| **Decrease** | Azaltmak, düşmek | Reduce, Diminish, Dwindle, Curtail, Decline | Increase, Augment, Amplify, Escalate |
| **Think** | Düşünmek, değerlendirmek | Ponder, Contemplate, Deliberate, Reflect on | Disregard, Ignore, Overlook, Dismiss |
| **Create** | Yaratmak, üretmek | Generate, Fabricate, Produce, Formulate, Innovate | Destroy, Demolish, Annihilate, Dismantle |
| **Destroy** | Yok etmek, yıkmak | Demolish, Annihilate, Devastate, Ruin, Raze | Construct, Build, Create, Restore |
| **Explain** | Açıklamak, izah etmek | Clarify, Elucidate, Elaborate, Illustrate, Expound | Confuse, Obscure, Confound, Muddle |
| **Obtain / Get** | Edinmek, elde etmek | Acquire, Procure, Attain, Secure, Gain | Lose, Forfeit, Relinquish, Surrender |
| **Use** | Kullanmak, yararlanmak | Utilize, Employ, Harness, Exploit, Apply | Neglect, Discard, Abandon, Waste |
| **Fix / Repair** | Tamir etmek, düzeltmek | Rectify, Mend, Restore, Overhaul, Resolve | Break, Damage, Impair, Ruin |
| **Ask** | Sormak, rica etmek | Inquire, Interrogate, Query, Solicit, Request | Answer, Reply, Respond, State |
| **Answer** | Yanıtlamak | Respond, Reply, Rebut, Counter, Acknowledge | Question, Inquire, Query, Ignore |
| **Avoid** | Kaçınmak, uzak durmak | Evade, Shunn, Elude, Bypass, Steer clear of | Confront, Face, Embrace, Tackle |
